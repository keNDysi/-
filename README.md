# Бот замен расписания — группа 33-п

Каждые 15 минут бот проверяет замены на сайте bgaek.by. Он накладывает их на обычное расписание и присылает итог в Telegram:
- 📅 сразу, как вывесят замены на сегодня или завтра. Если замены потом поправят, придёт 🔁 обновление;
- ℹ️ в 20:00, если замены на завтра так и не вывесили. Тогда приходит обычное расписание.

## 1. Создать бота в Telegram
1. Напиши **@BotFather** → `/newbot` → придумай имя → получишь **токен** (вида `123456:ABC...`).
2. Открой своего нового бота и нажми **Start** (напиши ему что-нибудь).
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates`.
   Найди `"chat":{"id":123456789` — это число и есть твой **chat id**.

## 2. Залить на GitHub (бесплатно, работает без компьютера)
1. Зарегистрируйся на github.com → **New repository** → имя любое, например `zameny-bot`, **Public**.
   В публичном репозитории запуски бесплатные без ограничений. Токен в коде не хранится, его никто не увидит.
2. **Add file → Upload files** → перетащи ВСЕ файлы из этой папки, включая папку `.github`.
   Если веб-загрузка не берёт папку `.github`, создай файл вручную через **Add file → Create new file**,
   имя `.github/workflows/bot.yml`, и вставь в него содержимое.
3. **Settings → Secrets and variables → Actions → New repository secret**:
   - `TG_TOKEN` — токен от BotFather
   - `TG_CHAT_ID` — твой chat id
4. **Actions** → включи workflows, если GitHub спросит → «Замены расписания» → **Run workflow**.
   Через минуту в Telegram должно прийти сообщение.

Дальше бот запускается сам. GitHub иногда опаздывает с запуском на 5–15 минут, это нормально.

## Запуск на своём ПК (вместо GitHub)
```
pip install -r requirements.txt
set TG_TOKEN=токен
set TG_CHAT_ID=число
python bot.py --loop
```
Проверять без отправки: `python bot.py --dry --debug`.

## Если расписание поменялось
Обычное расписание лежит в `base_schedule.json`. День: 1 = понедельник … 6 = суббота.
Номер — номер урока, `null` — урока нет.
